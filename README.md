# Blockchain-SocialMediaApp

🚀 **Introducing DecentraSocial — A Decentralized Social Media Platform!** 🌐

I'm excited to share my project, **DecentraSocial**, a social media application designed to bring together social networking and blockchain-inspired technology.

💻 **Explore the Live Application:**

🌐 **Frontend:** https://blockchain-socialmediaapp-1.onrender.com

⚙️ **Backend API:** https://blockchain-socialmediaapp.onrender.com

🩺 **API Health Check:** https://blockchain-socialmediaapp.onrender.com/api/health

✨ **Key Features:**
- 🔐 User registration and login
- 👛 Wallet address integration
- 📝 Create and share text posts
- 🖼️ Image uploads and media posts
- 📰 Social feed
- 👤 User profiles and user search
- 💬 Messaging interface
- 🔔 Notifications
- 📖 Stories and social interactions
- 🛡️ Moderation and privacy options

🛠️ **Technologies Used:**
- Frontend: React, TypeScript, and Vite
- Backend: Node.js, Express.js, and TypeScript
- Database: MongoDB Atlas
- Deployment: Render
- Blockchain/Web3 integration: Wallet connectivity

🎯 **What I learned:**

Building and deploying this project helped me gain practical experience in full-stack development, REST API integration, database connectivity, authentication, and cloud deployment.

This is an ongoing project, and I'm looking forward to improving its functionality and user experience.

I'd love to hear your feedback and suggestions!
